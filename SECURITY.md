# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately by emailing cloudinabottle@imbue.com.

Do not open a public issue for security problems.

Include what you found, how to reproduce it, and the version or commit you tested against.

## Scope

This covers the code in this repository and the apps we package. Vulnerabilities in a third-party app itself should be reported to that app's maintainers.

## Supported versions

We fix security issues in the latest release.
